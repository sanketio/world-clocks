# Changelog

All notable changes to this project will be documented in this file, per [the Keep a Changelog standard](http://keepachangelog.com/), and will adhere to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-08-27
### Changed
- Minimum supported WordPress version is now 6.6.
- Bump WordPress "tested up to" version to 7.1.

### Fixed
- AM/PM indicator no longer disappears from analog clocks on WordPress 7.1.
- Timezones are stored as IANA identifiers, so clocks work on sites in any language. Clocks saved by earlier versions keep working without being re-saved.
- Editor preview now matches the frontend for timezones such as Asia/Ho Chi Minh.

[1.1.0]: https://github.com/sanketio/world-clocks/tree/1.1.0
